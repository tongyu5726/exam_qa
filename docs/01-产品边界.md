# 01 产品边界

> 溯知（exam-rag）· 据源而答的课程资料问答  
> 当前功能边界；演进记录见 04-后续演进规范.md

---

## 1.1 用户场景

系统面向三类使用场景，按优先级排列：

| 优先级 | 场景 | 典型行为 | 频率 |
|--------|------|---------|------|
| P0 | 自由问答 | 输入自然语言问题（如「傅里叶变换的时移性质是什么」），系统从资料中检索并生成回答 | 高频 |
| P1 | 知识点检索 | 输入知识点名称（如「卷积定理」），系统聚合该知识点在全部资料中的相关内容 | 中频 |
| P2 | 章节概览 | 选择某一章节，系统生成该章的知识清单、重点标注、推荐自测题 | 低频（期末前集中使用） |

## 1.2 核心业务逻辑

系统有两条独立流水线：**入库**与**查询**。所有问答场景默认共享 Agent 决策入口，RAG 作为注册工具提供据源回答能力。

```
【入库】上传 → 解析 → 分块 → 向量化 → 写入（向量库 + 文档元数据）
【查询】用户输入 → 意图与会话范围 → Agent 决策 ↔ 工具（RAG 检索/生成、补充取证）→ 校验依据 → 返回
```

三种模式在检索与生成阶段有差异，检索能力按阶段增强：

| 模式 | 阶段 | 检索 | 生成 |
|------|------|------|------|
| 自由问答 | P0 | 向量检索 top_k | 默认 QA prompt |
| 自由问答 | P1 | 向量 + BM25 → RRF 融合 | 同上 |
| 自由问答 | P2 | + BGE-Reranker 精排 | 同上 |
| 知识点检索 | P1 | 同 P1 检索链 | 聚合 prompt（定义→公式→例题） |
| 章节概览 | P2 | 按章节元数据聚合，不走语义检索 | 概览 prompt |

**拒答（P0 必做）**：最高检索分低于阈值时，返回 `grounded: false`，回答固定为「资料库中未找到相关内容」，禁止无引用片段硬编。

不在此范围内的场景不做：闲聊、通用知识问答、文档在线编辑。PDF 支持同一课程内的自动版本更新，但不提供多人协作式的文档版本管理。

## 1.4 本地端 Agent vs 网页端 Agent

本项目的 Agent 以课程学习任务为核心，RAG 是其据源回答工具。身份介绍、模型说明、能力说明、问候致谢和上传使用帮助属于产品交流，不要求课程证据；课程知识与课程任务仍须检索、引用与校验，不提供无依据的课程结论。两种形态如下：

| 维度 | 本地端 Agent | 网页端 Agent |
|------|-------------|-------------|
| 定义 | 跑在用户本机的复习智能体运行时 | 同一智能体的浏览器交互界面 |
| 核心能力 | 资料入库、向量检索、引用生成、低分拒答 | 发问、上传、展示回答与 citations |
| 数据 | `data/`、`ChromaDB`、`SQLite` 均在本地 | 不持久化资料库，仅会话 UI 状态 |
| 代码落点 | `src/services/`（编排）+ `src/apis/`（HTTP 出口） | `frontend/src/features/`（Vue 页面） |
| 关系 | **能力本体** | **接入方式**，调用本地端 API，不 duplicate RAG |

P0 本地端 Agent 与网页端工作台均已实现，共享同一套 `/api/v1` 接口。

## 1.5 据源练习与复习

网页支持单题练习、作答历史、错题重练和今日复习。提交前不公开答案、解析和证据摘要；选择题按冻结选项自动判分，主观题提交后由用户对照依据自评。重练新增记录，题库编辑或删除不改写历史快照。记录按课程隔离，存储在本地 SQLite，不引入用户登录、长期对话记忆或掌握度预测。

问答可固定人工维护的资料场景与证据生效日；默认保持问题识别和追问继承。引用展示版本、生效期、权威和择证理由。检索命中但无法支持问题核心结论时，同样返回固定拒答和 `grounded=false`。详见 `08-练习与问答质量.md`。


## 对话出题任务

可直接提问：“根据第三章资料生成 5 道中等难度选择题，保存为草稿”。缺少主题、题数或题型时先补全需求，Agent 再取证、生成、独立校验并按授权保存；未要求保存时只预览。支持同对话重试、停止及题目定位，单一题型出题或混合题型组卷均支持一批 1—10 道，默认最多 6 轮工具调用。组卷蓝图明确每种题型的数量与分值，总分不一致时先澄清。

任务状态保存在按课程隔离的对话检查点；无有效证据或校验失败不保存，已保存批次重试不重复新增。完整 API、授权与恢复契约见 [后续演进规范](04-后续演进规范.md) 的“对话出题任务”。

组卷示例：“根据第三章资料组卷，1道选择题每题5分，1道简答题每题10分，总分15分，缺题允许补题，只预览”。确认预览后发送“保存试卷”。默认只复用题库，明确允许补题才生成；无有效依据、题目或资料变更、校验失败均不得保存半份结果。对话实时显示实际工具执行记录，保存后可打开试卷详情。


复习目标使用 `src/services/agent/study_goals.py` 的当前对话计划层：限定讲解、自测、错项复习，隐藏未提交答案，按反馈调整剩余计划，完成前复核资料和过程条件。默认不保存，明确授权才调用原有题库保存链路；不推断掌握度，不增加跨会话记忆。完整契约见 `docs/04-后续演进规范.md`「对话复习目标」。
